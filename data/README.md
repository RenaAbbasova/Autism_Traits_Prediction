# Data

The data file is not stored in this repository.

The dataset is the *ASD risk-factor screening data* published on Kaggle (`uppulurimadhuri/dataset`):
https://www.kaggle.com/datasets/uppulurimadhuri/dataset

Put the file in this folder as `data/data_csv.csv`. It has 1,985 rows and 28 columns: ten screening questions (`A1` to `A10`), the
Q-Chat-10 score, a social-responsiveness score, a childhood-autism rating, demographics, family history, several associated conditions
and the column `ASD_traits`.

Its provenance is not documented. See the README for what the analysis found about how the file seems to have been assembled.
